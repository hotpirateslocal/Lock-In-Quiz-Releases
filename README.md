# Lock In Launcher

Download the Launcher, then choose **Download Lock In Quiz** inside it.

## Download

| Your computer | Latest Launcher |
| --- | --- |
| Windows 10/11, 64-bit Intel or AMD | **[Download for Windows](https://github.com/hotpirateslocal/Lock-In-Quiz-Releases/releases/latest/download/LockInLauncher-Setup-1.0.1.exe)** |
| Mac with Apple Silicon — M1 or later | **[Download for Apple Silicon](https://github.com/hotpirateslocal/Lock-In-Quiz-Releases/releases/latest/download/LockInLauncher-1.0.1-macos-arm64.dmg)** |
| Mac with an Intel processor | **[Download for Intel Mac](https://github.com/hotpirateslocal/Lock-In-Quiz-Releases/releases/latest/download/LockInLauncher-1.0.1-macos-x86_64.dmg)** |

Mac requires macOS 14.4 or later. On Mac, drag **Lock In Launcher** into Applications and open it. Choose **Download Lock In Quiz**, then drag **Lock In Quiz** from its downloaded DMG into Applications.

Windows installs the Launcher separately; the Download button opens the Quiz installer. You can create a direct Quiz shortcut and open Quiz whenever you want. The Launcher handles optional updates and repair even if Quiz cannot open. Opening an installed Quiz works offline; downloads and update checks need an internet connection.

These initial installers are unsigned on Windows and ad-hoc signed on Mac. Your system may ask for confirmation. On Mac, use **System Settings → Privacy & Security → Open Anyway** if needed.
